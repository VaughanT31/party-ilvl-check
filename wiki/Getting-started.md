# Getting started

*Install it, and the window opens on the next ready check and checks everyone.*

Party iLvl Check shows who's ready, and your group's item levels, Mythic+ scores, buffs and gear checks, the moment a ready check starts.

### Install

1. **CurseForge app:** search for **Party iLvl Check** and click Install.
2. **By hand:** download it from [CurseForge](https://www.curseforge.com/wow/addons/party-item-level-checker) and put the **ilvlcheck** folder in `World of Warcraft\_retail_\Interface\AddOns`.
3. Start the game, or type `/reload`.

### First use

1. **Start or answer a ready check** in your party. A small window pops up and inspects everyone.
2. Each line shows the player's ready check icon (ready, not ready or still waiting), item level (orange when under your minimum) and only what they're missing. The top says who's ready, your own gear's durability and any utility nobody brings.
3. It fades out a few seconds after the ready check ends, and hides at once when a pull timer starts (`/pull`, `/countdown` or an addon's pull timer).
4. Click it for the full window. See [Reading the window](Reading-the-window.md).
5. Once a Mythic+ timer is running both windows stay hidden, so they never get in the way of a key.

### Place the ready check window

Drag it anywhere and it stays there. To place it without a ready check, click **Test Mini** in the full window (or type `/ilvlcheck mini`): it shows for 30 seconds. `/ilvlcheck mini reset` puts it back.

In raids it's off by default. `/ilvlcheck raidpopup on` turns it on: a raid lists only the people who aren't ready or are missing something.

Prefer the full window opening when you enter a dungeon, as it did before 1.6? Type `/ilvlcheck popup dungeon` (`popup both` for both, `popup off` to only open it yourself).

Open it any time with `/ilvlcheck` or the minimap button. Want to see it outside a dungeon? Use **Test M+** in the window. See [Window, size and test mode](Window-size-and-test-mode.md).
