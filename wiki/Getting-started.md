# Getting started

*Install it and walk into a dungeon: the window opens and checks everyone.*

Party iLvl Check shows your group's item levels, Mythic+ scores, buffs and gear checks the moment you zone into a dungeon.

### Install

1. **CurseForge app:** search for **Party iLvl Check** and click Install.
2. **By hand:** download it from [CurseForge](https://www.curseforge.com/wow/addons/party-item-level-checker) and put the **ilvlcheck** folder in `World of Warcraft\_retail_\Interface\AddOns`.
3. Start the game, or type `/reload`.

### First use

1. **Enter a 5-player dungeon** with your group. The window opens and inspects everyone.
2. Read each player's row. See [Reading the window](Reading-the-window.md).
3. Once a Mythic+ timer is running the window stays hidden, so it never gets in the way of a key.

Open it any time with `/ilvlcheck` or the minimap button. Want to see it outside a dungeon? Use **Test M+** in the window. See [Window, size and test mode](Window-size-and-test-mode.md).
