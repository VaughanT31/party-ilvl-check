# Buffs and gear checks

*The ring of icons on each row: class buffs, food, flask, augment rune, weapon oil, enchants and gems.*

Each row has a ring of icons: **green** when active, **red** when missing. Hover one to see which it is.

| Icon | Checks |
|---|---|
| **Class buffs** | Mark of the Wild, Battle Shout, Arcane Intellect, Power Word: Fortitude, Blessing of the Bronze, Skyfury |
| **Well Fed** | Any Midnight food or feast, including the reduced *Hearty* buff from someone else's feast |
| **Flask** | Midnight flasks |
| **Augment rune** | Any augment rune. Optional: a missing one is grey, not red |
| **Weapon oil** | Oils and whetstones on your weapon. Only shown for you: the game doesn't share other players' weapon enchants |
| **Enchants and gems** | Missing enchants and empty sockets on everyone's gear. Hover it for which slots |

### Tier set

Hover the gear icon to see how many tier set pieces each player wears.
