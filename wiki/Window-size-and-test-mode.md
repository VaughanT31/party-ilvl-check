# Window, size and test mode

*Moving and resizing the window, the minimap button, and trying it out of a dungeon.*

### Test M+ and Test Raid

**Test M+** fills the window with a made-up five-player group and **Test Raid** with a made-up raid, so you can see how it looks anywhere. Only one can be on at a time; click the ticked one again to leave test mode.

### Size

Drag the grip in the bottom-right corner to make the window smaller or bigger (50% to 200%), or type `/ilvlcheck scale 0.8`. `/ilvlcheck scale reset` brings back the normal size. The size is remembered.

### Minimap button

Click it to open the window. Drag it to move it around the minimap.
