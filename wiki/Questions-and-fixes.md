# Questions and fixes

*Answers to the things people ask most.*

**A player stays on "Scanning..." or "Out of range".**

The game only lets you inspect players near you. Party iLvl Check checks them again by itself once they come close, and retries failed inspects every 20 seconds while the window is open.

**The window doesn't open in a raid.**

That's on purpose, so it doesn't pop up on twenty people. Open it with `/ilvlcheck` or the minimap button.

**The window disappeared during my key.**

It stays hidden while a Mythic+ timer runs, so it never gets in the way. Open it with `/ilvlcheck` if you want it.

**Other players' keys don't show.**

The game doesn't share other players' keys. They show when an addon that shares them, such as BigWigs, is loaded.

**Weapon oil only shows for me.**

The game doesn't share other players' weapon enchants, so only yours can be checked.

**Someone has an interrupt but the bar says they don't.**

The utility bar works from class and spec. A talent choice can add or remove an ability, so treat it as a guide.

**Reporting a bug.**

Type `/console scriptErrors 1` (or use BugSack), then share the addon version, what you did and the error text on Discord.
